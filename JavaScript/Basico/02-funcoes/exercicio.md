# Funções

1. Crie a função `somar(a, b)` que retorna a soma dos dois valores.
2. Crie a função `ehPar(numero)` que retorna `true` se o número for par e `false` se for ímpar.
3. Crie a função `saudacao(nome)` que retorna uma mensagem diferente dependendo do horário (`new Date().getHours()`): "Bom dia", "Boa tarde" ou "Boa noite".
4. Crie a função `maiorDeTres(a, b, c)` que retorna o maior dos três números.
