# Arrays e Loops

1. Crie um array com 5 nomes. Use um `for` para mostrar cada nome no console.
2. Crie um array com 10 números. Use `for` para somar todos e mostrar o total.
3. Use um `while` para mostrar apenas os números pares de 0 a 20.
4. Use `switch` para receber um número de 1 a 7 (prompt) e mostrar o dia da semana correspondente.
5. Crie um array de objetos `produtos` (nome e preço). Use `for` para mostrar o nome de cada produto que custa mais de R$50.
