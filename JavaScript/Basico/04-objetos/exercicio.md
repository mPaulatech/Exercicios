# Objetos

1. Crie um objeto `carro` com `marca`, `modelo` e `ano`. Mostre uma frase no console usando os 3 dados.
2. Crie um array `funcionarios` com 3 objetos (nome, cargo, salario). Use um `for` para mostrar quem ganha mais de R$3000.
3. Adicione um método `apresentar()` dentro do objeto `carro` que retorna uma frase com os dados do carro (`this.marca`, etc).
4. Crie uma função `criarUsuario(nome, idade)` que retorna um objeto `{nome, idade}`.
