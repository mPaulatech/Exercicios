# Template Strings

1. Crie variáveis `nome`, `cargo` e `empresa`. Monte uma frase usando template string (crase, `${}`).
2. Crie um objeto `produto` (nome, preço, quantidade). Usando template string, mostre: "Nome - Preço unitário: R$X - Total: R$Y" (preço x quantidade).
3. Refaça o exercício 2 da pasta `04-objetos` (funcionários que ganham mais de R$3000), mas mostre a frase usando template string ao invés de concatenação com `+`.
