# Temporizadores

1. Use `setTimeout` para mostrar "Carregando..." e, depois de 2 segundos, mostrar "Pronto!".
2. Crie um contador regressivo de 10 a 0 usando `setInterval`, mostrando cada número na tela (`innerHTML`). Quando chegar em 0, pare o `setInterval` com `clearInterval`.
3. Crie um botão que, ao clicar, inicia um cronômetro (segundos contando pra cima) até o usuário clicar em outro botão "Parar".
