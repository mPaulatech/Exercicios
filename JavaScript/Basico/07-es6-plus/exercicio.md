# ES6+

1. Reescreva a função `somar(a, b)` da pasta `02-funcoes` como arrow function.
2. Use destructuring para extrair `nome` e `idade` de um objeto `pessoa` em duas variáveis separadas.
3. Use spread operator (`...`) para juntar dois arrays de números em um só.
4. Use `map()` para criar um novo array com o dobro de cada número de um array original.
5. Use `filter()` para pegar só os números maiores que 10 de um array.
