# Projeto: Conversor de Moedas

Igual ao seu `CalcIMC`, mas aplicando tudo que você já viu.

1. Faça um formulário com um campo para valor em Reais e um botão "Converter".
2. Ao clicar, converta o valor para Dólar e Euro (use uma cotação fixa no código, ex: 1 USD = R$5,40).
3. Mostre o resultado formatado (2 casas decimais) usando template string.
4. Trate o caso do campo vazio: mostre um alerta pedindo pra preencher o valor.
5. Bônus: use `setTimeout` para mostrar "Calculando..." por 1 segundo antes de exibir o resultado.
